# omerfaruksaral.com

Ömer Faruk Saral kişisel CV / tanıtım sitesi.

## Yerel önizleme

`index.html` dosyasını tarayıcıda açmanız yeterli. Build adımı yok.

## WinSCP ile yayınlama

1. Bu klasördeki dosyaları indirin / klonlayın.
2. WinSCP ile hosting’e bağlanın.
3. Şu dosyaları site köküne (`public_html`, `www` veya `httpdocs`) yükleyin:
   - `index.html`
   - `styles.css`
   - `script.js`
4. `https://omerfaruksaral.com` adresini kontrol edin.

## İçerik

Deneyim, proje ve iletişim bilgileri LinkedIn / CV içeriğine göre hazırlanmıştır.
